# AI 技能清单

「AI 助手」里的功能按“同学求职时会问 AI 的问题”来设计。每个技能有自己的专家方法和回答格式；在「问 AI」里提问时，插件先按关键词选技能（不花钱、不发送任何内容），选不出来再让模型只看问题本身判断，也可以手动指定。

代码：`src/lib/ai/chatSkills.ts`（对话技能）、`src/lib/ai/skills/`（有专门界面的四个技能）、`src/lib/ai/router.ts`（自动选技能）。

## 所有技能共守的规则

- 只用档案里的真实经历，不编造公司、项目、数字、证书；缺数字用【待补充】标出。
- 贡献动词按证据分级：协助/支持 < 参与 < 负责 < 推动 < 主导，不越级，不把团队成果算成个人的。
- 不帮助作弊：不代做在线笔试和测评，只讲题型和备考方法。
- 发给 AI 的内容去掉姓名、电话、邮箱、身份证号、出生日期、籍贯户口、家庭成员。

## 技能和对应的问题

| 技能 | 同学会怎么问 | 带不带经历 |
|---|---|---|
| 简历诊断 | 帮我看看简历哪里要改；能过大厂初筛吗；简历给打个分 | 带 |
| 经历润色 | 这段实习怎么写更有说服力；用 STAR 改一下；项目经历太平淡 | 带 |
| 岗位分析 | 这个 JD 我符合吗；岗位看重什么；简历要怎么针对这个岗位改 | 带 |
| 网申问答题 | 为什么选择我们（500 字）；最有成就感的事；遇到的困难；职业规划 | 带 |
| 自我介绍 | 1 分钟自我介绍；3 分钟版本；英文自我介绍；群面开场 | 带 |
| 模拟面试 | 这个岗位面试会问什么；模拟一场 HR 面；项目会被怎么深挖 | 带 |
| 回答点评 | 我这样回答“你的缺点”可以吗；帮我点评这个回答 | 不带 |
| 群面准备 | 无领导小组讨论怎么表现；选什么角色；排序题怎么破 | 不带 |
| 投递沟通文案 | Boss 直聘打招呼语；投递邮件怎么写；找学长内推怎么开口 | 带 |
| 求职邮件 | 问 HR 面试结果怎么开口；改约面试；礼貌拒 offer；面试感谢信 | 不带 |
| 通知整理 | （粘贴笔试/面试通知）帮我整理时间、链接和要准备的东西 | 不带 |
| 笔试测评准备 | 北森测评考什么；行测怎么准备；性格测试要注意什么 | 不带 |
| Offer 选择 | 两个 offer 怎么选；年包怎么算；三方毁约有什么后果 | 不带 |
| 谈薪 | 期望薪资填多少；HR 压价怎么回 | 不带 |
| 方向选择 | 我这个专业适合投什么岗位；大厂还是国企；考研还是工作 | 带 |
| 英文简历 | 把简历翻成英文；这段经历英文怎么写 | 带 |
| 求职问答 | 秋招什么时候开始；实习和秋招冲突怎么办（以上都不是时用） | 不带 |
